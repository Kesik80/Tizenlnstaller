# Tizenlnstaller

Репозиторий обслуживает [WgtInstaller](#wgtinstaller) — мою сборку Apps2Samsung
для установки Tizen-приложений на телевизоры Samsung.

Приложение при каждом запуске читает отсюда каталог: какие приложения показывать,
откуда их качать, какие у них описания и картинки.

## Файлы

| Файл | Зачем |
|---|---|
| `third-party-apps-01.json` | Главный каталог: список провайдеров и картинки к приложениям |
| `third-party-apps-info.md` | Описания приложений для экрана «App catalog» |
| `sources.json` | Ссылки на приложения из чужих источников. **Собирается автоматически** |
| `.catalog-state.json` | Состояние прошлой проверки, нужно чтобы не слать одно и то же |
| `.github/workflows/catalog.yml` | Раз в сутки обновляет `sources.json` и следит за ссылками |
| `index.html`, `api/check.js` | [WgtRadar](#wgtradar) — страница проверки источников |
| `sw.js`, `icons/`, `splash/` | PWA: service worker, иконки и экраны загрузки |
| `img/` | Превью приложений, 700×500 |
| Релиз `v1.0.0` | `.wgt`, которые я держу у себя |

## Откуда берутся приложения

Провайдеров два.

**`kesik80-tizeninstaller`** — ассеты релиза `v1.0.0` этого репозитория.
Там лежат приложения, у которых нет постоянного внешнего источника:
Media_Station_X, MyTuner, TizenTube.

**`sources`** — файл `sources.json`, ссылки на чужие сайты и репозитории:
Alpac, ICVA, KinoPub, Lampa, OttPlayer, Prisma.

Провайдер закреплён на теге `v1.0.0`, а не на «последнем релизе» — иначе любой
новый релиз подменил бы список приложений.

## Как добавить приложение

**Свой `.wgt`:** приложить файлом к релизу `v1.0.0` (новый релиз не создавать),
положить картинку в `img/`, дописать строку в `third-party-apps-info.md`
и запись в `communityApps`.

**Чужой источник:** дописать строку в `catalog.yml`, в один из трёх словарей:

- `STATIC` — ссылка постоянная, просто переносится в файл
- `GITHUB` — берётся самая свежая сборка из релизов чужого репозитория
- `PROBE` — в ссылке зашита версия, воркфлоу перебирает номера вверх

Затем Actions → catalog → Run workflow. Картинку и описание добавить так же,
как для своего.

## Картинки

Ищутся **по вхождению**: приложение идёт по `communityApps` сверху вниз и берёт
первый `matchName`, который содержится в названии. Поэтому более длинное имя
должно стоять выше более короткого — иначе `Zona` перехватит картинку у
`Zonamobi`. Список отсортирован по убыванию длины имени, так и держать.

Проверять руками не обязательно — есть [редактор](#редактор) с разбором.

## third-party-apps-info.md

Парсится только таблица. Обязательны колонки `Application` и `Description`,
`Version` необязательна. Таблица кончается на первой строке, не начинающейся с `|`.

Правки в обоих файлах подхватываются **всеми установленными сборками при
следующем запуске**, пересобирать APK не нужно. Перед коммитом стоит проверить:
`python3 -m json.tool third-party-apps-01.json`

## Редактор

`third-party-apps-01.json` и `third-party-apps-info.md` удобнее править
в редакторе — он показывает обе таблицы одним списком, тянет строки
перетаскиванием и сразу говорит, какая картинка какому приложению достанется.

## WgtRadar

Страница в корне репозитория, развёрнута на Vercel. Показывает по каждому приложению,
жива ли ссылка, что отдаёт сервер, какого размера файл и какая версия внутри пакета —
она читается из `config.xml`. Оттуда же можно скачать любой `.wgt` напрямую.

Проверка идёт через `api/check.js`: из браузера чужие домены не опросить,
они не отдают CORS-заголовки.

Ставится как приложение: кнопка «Установить приложение» в панели или пункт меню
браузера. С домашнего экрана доступны два ярлыка — «Проверить» и «Версии»,
они открывают страницу и сразу запускают обход ссылок.

Service worker кеширует только оболочку. Данные и `api/check` всегда идут в сеть,
кеш подставляется, лишь когда связи нет.

Самый частый случай поломки — домен истёк, и вместо файла отдаётся страница-заглушка.
Такое ловится по типу содержимого, а не по коду ответа: некоторые сайты на
несуществующий файл отвечают `200` и html.

## Уведомления

То же самое воркфлоу делает раз в сутки. Если ссылка сломалась или починилась
обратно — приходит сообщение в Telegram и запуск падает с красным крестом.
Пока состояние не меняется, никаких сообщений: одна сломанная ссылка не должна
писать каждый день.

Нужны два секрета в Settings → Secrets and variables → Actions:
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Без них шаг просто пропускается.

## Токен GitHub

Если список приложений вдруг стал пустым — это почти наверняка лимит API:
60 запросов в час на адрес без авторизации. Признак характерный: экран
«App catalog» продолжает работать, потому что описания и картинки грузятся
с `raw.githubusercontent.com`, где лимита нет.

Лечится токеном: в приложении шестерёнка → «GitHub token (PAT)». Прав хватает
на чтение публичных репозиториев. Токен живёт в SecureStorage: переустановку
начисто не переживёт, обновление поверх — переживёт.

## WgtInstaller

Сборка [Apps2Samsung](https://github.com/Apps2Samsung/Apps2Samsung) (MIT, Patrick Stel)
с моей иконкой и каталогом из этого репозитория. Отличия от оригинала:

- каталог приложений и описания берутся отсюда, а не из апстрима
- секция Jellyfin builds на экране «App catalog» скрыта
- проверка обновлений отключена, APK обновляю вручную

Package остался `nl.madebypatrick.apps2samsung`, так что поверх официального
Apps2Samsung сборка не встанет и наоборот.
